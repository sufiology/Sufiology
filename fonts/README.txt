Anaktoria font (public domain, by George Douros).
The download (anaktoria.zip) holds two files: Anaktoria.ttf and Anaktoria_hint.ttf.
Put ONLY Anaktoria.ttf in THIS folder, with exactly that name. Do not use Anaktoria_hint.ttf (it is bigger and not needed on screen).
The font has one style, so the browser makes bold and italic from it.
Upload the fonts folder to GitHub with the rest of the site.
